Halvora Studio

Halvora Studio is a private tool used by the owner of a small group of YouTube channels to manage their own channels.

With the owner's permission, the tool uses the YouTube Data API and YouTube Analytics API to:

  • upload videos to the owner's channels;
  • set titles, descriptions, thumbnails and captions, including translated versions;
  • read channel and video statistics to evaluate the owner's content.

The tool is not offered to the public and does not access channels or data of other users.
